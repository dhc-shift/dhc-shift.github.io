About

문제를 정의하고, 작게 만들고, 함께 검증합니다.

동아리 소개, 운영 철학, 대상 학과, 활동 방식 등 공식 홈페이지에 들어갈 핵심 문구를 이곳에 배치합니다.

SHIFT는 학술 탐구와 실무형 제작 사이의 간격을 줄이는 프로젝트 중심 학술 동아리입니다. 구성원은 관심 분야별 스터디와 팀 프로젝트를 통해 문제를 발견하고, 데이터를 수집하며, 프로토타입과 발표 자료로 결과물을 정리합니다.

이 문단은 placeholder입니다. 동아리의 실제 목표, 학과 연계성, 선발 기준, 정기 모임 요일, 운영진 메시지 등으로 교체해 사용할 수 있습니다.

Build 아이디어를 문서, 코드, 데이터, 데모 형태로 빠르게 구체화합니다.
Learn 기초 온보딩부터 심화 트랙까지 함께 학습하는 구조를 만듭니다.
Share 세미나, 회고, 데모데이를 통해 결과와 시행착오를 공유합니다.

Activities

정기 활동

학기 중 운영되는 대표 활동을 카드 형태로 소개합니다. 실제 운영 항목에 맞게 제목과 설명을 수정하세요.

Weekly Session

정기 세미나

관심 주제 발표, 논문/아티클 리뷰, 산업 동향 공유를 진행합니다. 발표자와 주제는 학기별 운영 계획에 맞춰 업데이트합니다.

Project Lab

팀 프로젝트

데이터 분석, 웹/앱 프로토타입, 서비스 기획 등 팀 단위 결과물을 만드는 활동입니다. 주제와 산출물 예시는 placeholder입니다.

Study Track

스터디 트랙

신입 부원을 위한 기초 온보딩과 관심 분야별 심화 스터디를 운영합니다. 난이도와 커리큘럼은 학기마다 조정됩니다.

Networking

커뮤니티 밋업

선배, 현업자, 타 전공 구성원과 연결되는 네트워킹 세션을 기획합니다. 게스트 정보와 일정은 추후 입력합니다.

Archive

지식 아카이브

스터디 노트, 발표 자료, 프로젝트 회고를 정리해 다음 기수도 이어서 사용할 수 있는 자료 구조를 만듭니다.

Demo Day

결과 공유회

학기 말 프로젝트 결과를 발표하고 피드백을 받는 자리입니다. 포스터, 깃허브, 발표 영상 링크를 연결할 수 있습니다.

Curriculum

학기 운영 흐름

신규 부원이 따라오기 쉬운 온보딩부터 프로젝트 발표까지의 흐름을 단계별로 보여줍니다.

Orientation & Tool Setup

동아리 소개, 협업 도구 세팅, Git/GitHub, 문서 작성 규칙 등 기본 환경을 맞춥니다.

Core Study Sprint

데이터 리터러시, Python/R, 웹 기초, AI 활용 등 공통 기초를 짧은 실습 단위로 학습합니다.

Problem Framing

팀별 관심사를 바탕으로 문제 정의, 리서치, 데이터 탐색, 기능 범위를 정리합니다.

Prototype & Review

분석 노트북, 대시보드, 웹 페이지, 발표 자료 등 실제로 보여줄 수 있는 산출물을 제작합니다.

Demo Day

결과 발표와 회고를 통해 다음 학기 프로젝트, 스터디, 운영 개선 과제를 정리합니다.

Projects

프로젝트 아카이브

공개 가능한 프로젝트를 소개하는 영역입니다. 프로젝트명, 기간, 참여자, 링크, 한 줄 성과로 교체하면 됩니다.

[Project 01] 데이터 기반 리서치

공개 데이터 또는 설문 데이터를 활용해 특정 문제를 분석하고 인사이트를 정리한 프로젝트 소개 문구가 들어갑니다.

Data Research 2026

[Project 02] 서비스 프로토타입

사용자 시나리오, 기능 설계, 화면 구성, MVP 제작 과정을 담은 프로젝트 소개 문구가 들어갑니다.

Prototype UX Team

[Project 03] AI 활용 실험

AI 모델, 자동화 도구, 프롬프트 워크플로 등을 활용해 실무 문제를 해결해 본 실험 내용을 소개합니다.

AI Automation Lab

[Project 04] 커뮤니티 리포트

세미나, 인터뷰, 산업 지도, 학술 자료를 바탕으로 제작한 리포트나 아카이브를 연결할 수 있습니다.
