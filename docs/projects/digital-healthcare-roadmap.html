Project 02

디지털헬스케어 산업지도

디지털헬스케어 산업에 어떤 분야와 직무가 있고, 각 직무에서 어떤 역량이 필요한지 정리하는 프로젝트입니다.

산업지도 구성

산업군 지도

병원정보시스템, 의료 AI, 웨어러블, 디지털 치료제, 바이오데이터 같은 산업군을 분류합니다.

직무군 지도

서비스 기획, 소프트웨어 개발, 데이터 분석, AI, 의료정보, 규제, 비즈니스 직무를 비교합니다.

전공-직무 매핑

프로그래밍, 데이터베이스, 통계, 보건의료정보학, 개인정보보호가 어떤 직무와 연결되는지 정리합니다.

직무군 예시

  • 서비스 기획 / 관리: 헬스케어 서비스의 문제와 요구사항을 정의합니다.
  • 소프트웨어 개발: 앱, 웹, API, 데이터베이스 연동 기능을 구현합니다.
  • 데이터 분석: 의료 데이터와 서비스 이용 데이터를 분석해 의사결정을 돕습니다.
  • 인공지능 / 머신러닝: 의료 데이터 기반 예측 모델이나 판독 보조 모델을 만듭니다.
  • 의료정보 / 병원정보시스템: EMR, EHR, 의료데이터 표준과 병원 업무 흐름을 다룹니다.
  • 규제 / 품질 / 개인정보보호: 의료 소프트웨어와 데이터 활용이 법과 규정을 지키도록 점검합니다.

정리 방식

  • 기업 카드에는 산업군, 주요 서비스, 핵심 기술, 관련 직무군, 필요 역량을 적습니다.
  • 직무 분석 카드에는 주요 업무, 필요 역량, 관련 전공, 추천 프로젝트를 적습니다.
  • 산업지도는 단순한 기업 목록이 아니라 전공 수업과 실제 직무의 연결을 보여주는 자료로 만듭니다.
  • 이후에는 검색, 필터, 태그 기반의 인터랙티브 지도로 확장할 수 있습니다.
